# Research archive

Every research round's results are kept here (marth 2026-11-10: "every research has its results saved so that over time we have a bigger knowledge base and research less"). Read this folder and Linux-Native-Tools BEFORE starting new research.

- Engine / reverse-engineering facts (addresses, vfuncs, layouts, what the engine does) also go into the cross-project knowledge repo `Linux-Native-Tools` (repo root files: known-hooks.md, actor-ai-and-packages.md, ...). That copy is the canonical one.
- Project research (design studies, field diagnoses, rulings, census results) goes here, one file per round, under a dated folder. Never delete; mark superseded findings in place.
- Rulings in these files are marth's words where quoted. The class-walkthrough-decisions file is the authoritative ruling log for the class update.
