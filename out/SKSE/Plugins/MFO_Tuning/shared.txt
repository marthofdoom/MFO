# MFO IAUS tuning file. It OVERRIDES the compiled values; delete a line (or the file) and that value goes back to the shipped one.
# Checked every ~2 seconds while the game runs: save a change and it is live a few seconds later, no restart. Not editable in game.
# One entry per line. '#' starts a comment. Blank lines are ignored. A bad line is skipped with a [tuning] warning in MFO.log (file, line, why);
# the rest of the file still applies. The syntax is the simulator's (tools/iaus_sim), so a tuning run's lines paste in unchanged.
#
# THIS FILE: the Tuning globals and the curves / weights shared by every class (the simulator's --set). Comma lists are allowed on one line.
#   t.<name>=<v>              a Tuning scalar: momentum postureMomentum preempt actFloor softCd occHold kite blockBase tauntCd powerCd disengageCd
#                             noHealDrink noHealRetreat emergencyHpHigh emergencyHpLow offClassBase groundCd blockCd bashCd backOffCd stepCd regroupCd
#   w.<family>.<cons>=<v>     a weight (exponent) override for EVERY class (family and cons are indexes; a class's own .w is overridden by it)
#   aw.<family>=<v>           a family's action weight
#   c.<cons>.a|b|floor=<v>    a shared curve's parameter (cons is an index)
# Example:  t.momentum=1.0
# Changing this file re-applies every class file on top of it (a class curve override starts from the shared curve).
# values: generated by the coordinator
