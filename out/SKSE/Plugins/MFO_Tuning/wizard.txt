# MFO IAUS tuning file. It OVERRIDES the compiled values; delete a line (or the file) and that value goes back to the shipped one.
# Checked every ~2 seconds while the game runs: save a change and it is live a few seconds later, no restart. Not editable in game.
# One entry per line. '#' starts a comment. Blank lines are ignored. A bad line is skipped with a [tuning] warning in MFO.log (file, line, why);
# the rest of the file still applies. The syntax is the simulator's (tools/iaus_sim), so a tuning run's lines paste in unchanged.
#
# THIS FILE: the 'wizard' class row only. The "wizard:" prefix on a line is optional; a line naming a different class is rejected.
#   [wizard:]<family>.<cons>.<param>=<v>    a curve override. <family> / <cons> are an index or a name; <param> is a | b | floor | zeroAbove | zeroBelow
#                                       | px0..px5 / py0..py5 (a Piece curve's points)
#   [wizard:]<family>.<cons>.w=<v>          this class's exponent on that consideration (v > 0)
#   [wizard:]family.<family>=<v>            this class's multiplier on a whole action family (v > 0)
#   [wizard:]equip.crossover=<v>            the weapon swap distance (both posture curves' midpoint at once)
#   [wizard:]scalar.<name>=<v>              drinkHealthLine | touchSpentSec | schoolPeak | schoolFloor | schoolShape | schoolMasteredBump
# Example:  wizard:equip.crossover=0.1125
# values: generated by the coordinator
